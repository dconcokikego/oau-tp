CSC 250

Data Structures and Algorithms

18 Lectures Intermediate Level Computer Science

Course Overview

Data Structures and Algorithms provides comprehensive coverage of fundamental data structures and algorithmic techniques essential for efficient software development. Students will learn to analyze algorithm complexity and choose appropriate data structures for various problems.

This course emphasizes both theoretical understanding and practical implementation. Topics include abstract data types, trees, graphs, sorting, searching, and algorithm analysis. Students will develop skills in designing efficient algorithms and understanding trade-offs between different approaches.

Learning Objectives

  • Understand and implement fundamental data structures including linked lists, stacks, queues, and trees
  • Analyze time and space complexity using Big-O notation
  • Master graph algorithms including traversal, shortest path, and minimum spanning trees
  • Implement and compare sorting and searching algorithms
  • Understand hash tables and collision resolution strategies
  • Apply dynamic programming and greedy algorithms to optimization problems
  • Make informed decisions about data structure selection for specific problems

Prerequisites

Mathematics: Discrete mathematics helpful. Comfort with mathematical notation and proofs.

Prior Knowledge: CSC 150 or equivalent programming experience. Solid understanding of functions, arrays, and recursion required.

Lecture Series

Lecture 1

Algorithm Analysis and Big-O Notation

Time and space complexity. Big-O, Big-Omega, and Big-Theta notation. Complexity analysis techniques.

55 minutes
Lecture 2

Linked Lists

Singly linked lists, doubly linked lists, and circular lists. List operations and implementations. Advantages over arrays.

55 minutes
Lecture 3

Stacks and Queues

Stack ADT and applications. Queue ADT and implementations. Circular queues and deques. Priority queues introduction.

55 minutes
Lecture 4

Recursion and Recurrence Relations

Recursive algorithm design. Solving recurrence relations. Master theorem. Recursion tree method.

60 minutes
Lecture 5

Trees: Binary Trees

Tree terminology and properties. Binary tree representations. Tree traversals: inorder, preorder, postorder.

55 minutes
Lecture 6

Binary Search Trees

BST property and operations. Insertion, deletion, and search. BST performance analysis. Balanced BSTs introduction.

60 minutes
Lecture 7

AVL Trees and Red-Black Trees

Self-balancing binary search trees. Rotations and rebalancing. Height guarantees and performance.

60 minutes
Lecture 8

Heaps and Priority Queues

Binary heap structure. Heap operations and heapify. Priority queue implementation. Heap sort algorithm.

55 minutes
Lecture 9

Hash Tables

Hash functions and collision resolution. Chaining and open addressing. Load factor and rehashing. Applications.

60 minutes
Lecture 10

Graphs: Representations and Traversals

Graph terminology. Adjacency matrix and adjacency list. Depth-first search and breadth-first search algorithms.

60 minutes
Lecture 11

Shortest Path Algorithms

Dijkstra's algorithm for single-source shortest paths. Bellman-Ford algorithm. All-pairs shortest paths.

60 minutes
Lecture 12

Minimum Spanning Trees

Prim's algorithm and Kruskal's algorithm. Union-find data structure. Applications of MSTs.

55 minutes
Lecture 13

Sorting Algorithms I

Comparison-based sorting lower bound. Merge sort and quicksort. Partition strategies and pivot selection.

60 minutes
Lecture 14

Sorting Algorithms II

Heap sort. Counting sort, radix sort, and bucket sort. Sorting algorithm comparison and selection.

55 minutes
Lecture 15

Dynamic Programming I

Principles of dynamic programming. Memoization and tabulation. Classic DP problems: Fibonacci, knapsack.

60 minutes
Lecture 16

Dynamic Programming II

Longest common subsequence. Matrix chain multiplication. Edit distance and string algorithms.

60 minutes
Lecture 17

Greedy Algorithms

Greedy choice property and optimal substructure. Activity selection. Huffman coding. Greedy vs dynamic programming.

55 minutes
Lecture 18

Advanced Topics and Algorithm Design

Divide and conquer strategies. Backtracking. Branch and bound. NP-completeness introduction. Algorithm design principles.

60 minutes

Course Information

This course requires approximately 6-8 hours of study per week including lecture viewing and practice problems.
