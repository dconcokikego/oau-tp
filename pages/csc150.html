CSC 150

Computer Science Fundamentals

14 Lectures Beginner Level Computer Science

Course Overview

Computer Science Fundamentals introduces core programming concepts, computational thinking, and problem-solving strategies. Students will learn to design algorithms, write clean code, and understand fundamental data structures and programming paradigms.

This course emphasizes conceptual understanding over any specific programming language. Students will develop skills in algorithm design, code organization, debugging, and testing that transfer across all programming environments and professional software development contexts.

Learning Objectives

  • Understand fundamental programming concepts including variables, control flow, and functions
  • Develop computational thinking and algorithmic problem-solving skills
  • Write, test, and debug programs using structured programming principles
  • Understand basic data structures including arrays, lists, and dictionaries
  • Apply programming concepts to solve real-world problems
  • Understand time and space complexity at an introductory level
  • Develop good coding practices and documentation habits

Prerequisites

Mathematics: High school algebra. Logical thinking and mathematical reasoning skills.

Prior Knowledge: No prior programming experience required. Course designed for beginners.

Lecture Series

Lecture 1

Introduction to Computing and Programming

Overview of computer science. Problem-solving with computers. Programming languages and development environments.

50 minutes
Lecture 2

Variables, Data Types, and Basic I/O

Variables and assignment. Primitive data types. Input and output operations. Type conversion.

55 minutes
Lecture 3

Operators and Expressions

Arithmetic, comparison, and logical operators. Expression evaluation. Operator precedence and associativity.

50 minutes
Lecture 4

Control Flow: Selection

Boolean expressions. If-else statements. Nested conditionals. Switch/case statements. Common pitfalls.

55 minutes
Lecture 5

Control Flow: Iteration

While loops, for loops, and do-while loops. Loop design patterns. Nested loops. Break and continue statements.

60 minutes
Lecture 6

Functions and Modularity

Function definition and invocation. Parameters and return values. Scope and lifetime of variables. Modularity benefits.

55 minutes
Lecture 7

Arrays and Lists

Array declaration and initialization. Array operations and iteration. Multi-dimensional arrays. Lists and dynamic arrays.

60 minutes
Lecture 8

Strings and String Processing

String representation and operations. String methods and manipulation. Pattern matching basics. Text processing applications.

50 minutes
Lecture 9

Dictionaries and Hash Tables

Key-value pairs and dictionary operations. Hash table fundamentals. Applications to counting and lookup problems.

55 minutes
Lecture 10

Algorithm Design Basics

Problem decomposition strategies. Pseudocode and flowcharts. Common algorithmic patterns. Step-by-step refinement.

55 minutes
Lecture 11

Searching and Sorting

Linear and binary search. Bubble sort, selection sort, and insertion sort. Algorithm efficiency introduction.

60 minutes
Lecture 12

Recursion

Recursive thinking and base cases. Recursive functions. Recursion vs iteration. Classic recursive problems.

55 minutes
Lecture 13

File I/O and Data Processing

Reading from and writing to files. CSV and text file processing. Error handling basics. Data parsing applications.

50 minutes
Lecture 14

Software Development Practices

Code organization and documentation. Testing and debugging strategies. Version control introduction. Next steps in CS.

55 minutes

Course Information

This course requires approximately 6-8 hours of study per week including lecture viewing and practice problems.
